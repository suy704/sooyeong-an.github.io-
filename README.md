# Patient Wait-Time Forecasting

## Overview

This project explores how healthcare operational data
can be used to predict patient wait times.

## Healthcare Problem

Increasing referral demand can create capacity pressure
and longer patient wait times.

## Dataset

Synthetic dataset containing:
- Referral volume
- Service capacity
- Historical wait time
- No-show rate
- Department
- Day of week

## Methods

- Data cleaning
- Exploratory data analysis
- Feature engineering
- Linear Regression
- Random Forest
- Model evaluation
